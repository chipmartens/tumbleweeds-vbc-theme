# Chez Koop build conventions (research for the Tumbleweeds port)

Written 2026-10-01 before any porting. Every rule in the checklist at the bottom is followed by this theme. Sources are read-only: public pages and public CSS/JS/source maps, the mode40 theme on the koop12 staging box (cat/ls/grep only, nothing changed), and the internal memory files.

### Source maps (0812 and Roadtrips publish `app.min.css.map` with sourcesContent)

- SCSS partial structure: `app.scss`, `base/_variables.scss`, `base/_mixins.scss`, `base/_fonts.scss`, `base/_animations.scss`, `base/_mobile-menu.scss`, `vendor/_reset.scss`, `vendor/_bootstrap.scss`, `vendor/_featherlight.scss`, `vendor/_gravityforms_base.scss`, `vendor/_gravityforms_theme.scss`, `components/_*.scss`.
- `app.scss` opens with the same six-band comment index in both sites (and in mode40): `00 Grid, 01 Base, 02 Layout, 03 Module, 04 State, 05 Theme`. Imports first (`@import "base/variables"; "base/mixins"; "vendor/reset"; "base/fonts"; "base/animations"; vendor; "vendor/bootstrap"`), then `:root { ... }` under `01. Base`.
- `base/_variables.scss` holds only SCSS vars: `$font-one`, `$section-padding`, `$container-width-sm..xxxl` (540/720/960/1140/1380/1560), `$breakpoint-width-sm..xxxl` (576/768/992/1200/1440/1600), `$grid-gutter: 30px` plus `-half/-double/-quarter` derivations, `$menu-breakpoint`.
- Tokens are CSS custom properties in `:root`, all prefixed: `--global--color-<name>` (+ `-rgb` twin when needed), `--global--color-primary`, `--global--color-background`, `--global--font-family-sans|primary|secondary`, `--global--font-size-<step>` with a paired `--global--line-height-<step>` generated by a mixin as `clamp(min, vw, max)`, `--global--font-weight-medium|bold`, `--global--border-radius-sm|xs`, `--grid--gutter(-half|-quarter|-double)`, `--section-padding`, `--container-width`, `--container-padding`. Breakpoint overrides of tokens sit in the same `:root` under `@media (min-width: ...)`.
- Components read tokens: `padding-top: var(--section-padding)`, `font-size: var(--global--font-size-xxxxl)`, `@include text(lg)`.
- Base section rules: `section { padding-top: var(--section-padding); position: relative }`, `section.no-top-padding`, `section.last-module { padding-bottom: var(--section-padding) }`, `.meta`, `.section__heading`, `.section__subhead`, `.content` for rich text.
- Misc partial names seen: `.alignleft/.aligncenter/.alignright`, `.screen-reader-text`, `.embed-container`, `.lazyload-image-wrapper`, `.row-center`, `.hbspt-form`, `html.js` pre-states for reveals, a "No JS Styles" band.

### Markup and JS patterns on the public pages

- Header: `header.site-header` (mode40, chezkoop) or `header.site__header` (roadtrips) > container > `.site-logo` (inline SVG) + `nav.site-nav` (`ul#menu-header.menu`, standard `menu-item` classes from `wp_nav_menu`) + `.menu-toggle`. Menu name `menu-header`.
- `body` classes are trimmed to `home page page-<slug>` (mode40 filters `body_class` with a whitelist and adds `<post_type>-<slug>`). `no-js` on `<html>` is swapped for `js` by an inline script.
- Section ids are `section-<heading-slug>` (Roadtrips: `section-luxury-sports-travel-package-specialists`) or `section-<n>` (0812). Last flex row gets `last-module`.
- Images: lazysizes (`class="lazyload"`, `data-src`, `data-srcset`, `data-sizes`, `data-aspectratio`), eager + `fetchpriority="high"` for the hero, `lazyload-image-wrapper` with padding-top ratio box, filtered srcset that drops the full-size original, descriptive alt text from the media library.
- Reveal pattern: `data-aos="fade-up"` / `.fade-up` and `.split-fade`, driven by GSAP + ScrollTrigger (AOS retired); CSS pre-state `html.js .fade-up { opacity: 0 }`.
- Libraries: jQuery (WP core, webpack external), GSAP + ScrollTrigger (+ SplitText), Lenis smooth scroll wired to the GSAP ticker, lazysizes, imagesLoaded, webfontloader (mode40 only), slick on older sites, featherlight lightbox, Font Awesome via CDN. No swiper found.
- Fonts: Typekit (chezkoop, roadtrips) or Google Fonts `<link>` in `header.php` (mode40). Preconnect hints in the head.
- Analytics tags go in `header.php` (GTM). Google Site Kit and Yoast on client sites.

### mode40 theme on koop12 (their real contract, read-only)

- Folder `mode40-2026`: `.cursor/rules/mode40-theme.mdc` (alwaysApply), `.cursor/rules/page-templates-location.mdc`, `.cursor/skills/mode40-theme/SKILL.md`, `acf-json/`, `assets/{css,img}`, `dist/js/app.bundle.js`, `docs/`, `inc/{lib,acf,migrations,plugins,class-tgm-plugin-activation.php}`, `page-templates/`, `src/{js,scss,img}`, `template-parts/`, `gulpfile.js`, `webpack.config.js`, `package.json`, `.gitignore` (node_modules, unused, .DS_Store, .env*).
- `functions.php` is only a list of `require_once('inc/lib/<file>.php')`: `setup, cpt, extras, query-args, sanitize, flex, shortcodes, disable-comments` then `acf, gravityforms`.
- `inc/lib/setup.php`: `register_nav_menus` (`header-menu`, `footer-menu`, `utility-links`), `add_theme_support` post-thumbnails + html5 + title-tag, `add_image_size` named ladder (`hero 1920x1080`, `sixteennine(-sm|-xs)`, `sixfour`, `fivefour`, `square`, `portrait`...) with `image_size_names_choose`, `add_editor_style('assets/css/editor-style.min.css')`, TGMPA registration (bundled ACF Pro zip + Gravity Forms zip in `inc/plugins/`, Classic Editor from wp.org), asset enqueue (`app-style`, `app-script` with `jquery` dependency, footer).
- `inc/lib/acf.php`: WYSIWYG `Minimal` toolbar, helper functions, validate hooks keyed to field keys. `inc/lib/cpt.php`: one `team` CPT + taxonomy. `inc/acf/acf-field-menu`: custom ACF `menus` field loaded by `autoload_includes()` in `extras.php`.
- `inc/lib/flex.php`: section helpers that **echo** classes from `get_sub_field()`: `section_meta($args)` (eyebrow, heading, subhead with BEM class args, `heading_nl2br`, `aos_type`), `section_text($pre,$post,$field)`, `section_cta($classes,$field,$icon)`, `section_bg_color()`, `section_color()`, `section_text_align()`, `section_border()/_top()/_bottom()`, `section_padding()`, `section_id($i)`, `is_last_row($i,$total)`, `numbered_sections()`, `section_feature_number()`, `accordion_setup()`, `render_hubspot_form()`.
- `inc/lib/extras.php`: `section_image($size,$obj,$classes,$wrapper,$srcset,$data,$disable_lazy,$alt)` (lazysizes output, aspect ratio map by size name, responsive `sizes` map, SVG inlined), `get_image_srcset_filtered`, `featured_image_obj`, `split_text`, `load_svg`, `extra_body_classes` whitelist, `section_should_hide`.
- `index.php`/`page.php`: `get_header(); get_template_part('template-parts/content','hero'); <main> get_template_part('template-parts/content','flexcontent'); </main>; get_footer();`.
- `template-parts/content-flexcontent.php`: `have_rows('flex_content', $flex_post_id)`; `$total_rows`, `$i`; one `if (get_row_layout() == 'section_x') ... elseif` chain; each branch outputs `<section id="<?php section_id($i); ?>" class="x<?php section_padding(); section_bg_color(); is_last_row($i,$total_rows); ?>"><div class="container-2xl">...`. `is_home()` resolves to the posts page ID.
- ACF flex layouts are named `section_<noun>` (`section_intro`, `section_cards`, `section_faq`, `section_cta_banner`, `section_team`, ...). Sub-field names: `section_eyebrow`, `section_heading`, `section_subhead`, `section_text`, `section_cta` (link), `section_image`, `section_border_top`, `section_bg_color`, `section_text_align`, `section_padding`. Repeaters get plain names (`faq_items`, `cards`, `stats`). Field group titles: "Page Content" (flex), "Hero Content" (`hero_*`), "Site Settings" and "Footer Content" (options), "Team Member Details" (CPT).
- ACF local JSON in `acf-json/` (`group_<id>.json`, `ui_options_page_<id>.json`), Pro options pages created in the UI and committed as JSON.
- Deploy: build locally (`gulp` default = sass + webpack + img + watch with BrowserSync proxy `mode40.local`), **compiled assets are committed** (`assets/css/app.min.css` + `.map`, `dist/js/app.bundle.js`), push, `git pull` on the server, no node on the server. Content changes go through WP-CLI `wp eval-file` migrations (`inc/migrations/*.php`) and `update_field()`.
- JS (`src/js/entry.js`): `window.theme = window.theme || {}`, ES imports for gsap/lenis/lazysizes at the top, one jQuery IIFE `(function($){ theme.init = ...; theme.animations = ...; theme.menus = (function(){...}()); $(function(){ theme.init(); theme.animations(); }); }(jQuery))`. `html.menu-open`, `html.scrolled`, `.nav-up/.nav-down`.
- BEM: block = layout noun (kebab), `block__element`, `block--modifier`; shared `.container-2xl`, `.content`, `.meta`, `.btn`, `.btn--<style>`; state hooks `is-open`, `last-module`, `data-aos`, `data-<thing>`.
- Cursor rules to follow: new page templates live in `page-templates/`, never `page-*.php` at the theme root; new flex layouts get JSON in `acf-json/` plus a branch in `content-flexcontent.php`, a single root BEM block, `section_meta()` + `section_text()` + `section_cta()` + `section_id()` + `is_last_row()`, styles in `app.scss` using `var(--global--*)` and `@include text()` before any one-off value.
- Chip's own rules on top: no mini-syntax in text boxes, Kind first then conditional fields, plain labels and one-line instructions, check the editor view in wp-admin (`feedback_wp_editor_proof_fields`); every block takes a token, never a literal (`feedback_layout_from_tokens_never_literals`); all content in WordPress via ACF, never hardcoded (`project_chez_koop_wordpress_stack`, 2026-09-25).

## 2. Checklist the port follows

Numbers are referenced by the review.

**Structure**
1. Theme root has `style.css`, `functions.php` (only `require_once('inc/lib/*.php')` lines), `header.php`, `footer.php`, `index.php`, `page.php`, `single*.php`, `404.php`, `template-parts/`, `page-templates/`, `inc/{lib,class-tgm-plugin-activation.php,plugins/}`, `acf-json/`, `src/{scss,js,img}`, `assets/{css,img}`, `dist/js/`, `gulpfile.js`, `webpack.config.js`, `package.json`, `.gitignore`, `.cursor/rules/*.mdc`, `docs/`.
2. `inc/lib/` split: `setup.php`, `cpt.php`, `extras.php`, `query-args.php`, `sanitize.php`, `flex.php`, `acf.php`. Helper names match the mode40 ones where the job is the same (`section_meta`, `section_text`, `section_cta`, `section_id`, `is_last_row`, `section_bg_color`, `section_padding`, `section_image`, `featured_image_obj`, `numbered_sections`).
3. `page.php` and `index.php` follow `get_header(); hero part; <main> flexcontent part; get_footer();`. New custom page templates only in `page-templates/`.
4. Menus registered as `header-menu`, `footer-menu`, `utility-links`; rendered with `wp_nav_menu`.
5. Image sizes registered with the named ladder; `image_size_names_choose` filter; `add_editor_style('assets/css/editor-style.min.css')`.
6. TGMPA registers the fields plugin and Classic Editor. No ACF Pro zip is committed (public repo); the fields plugin entry is satisfied by Secure Custom Fields from wordpress.org or by ACF Pro already being active (`is_callable`).

**Content model**
7. One ACF flexible field `flex_content` in the group "Page Content"; layout names `section_<noun>`; sub-field names reuse the Koop vocabulary (`section_eyebrow`, `section_heading`, `section_text`, `section_cta`, `section_image`, `section_bg_color`, `section_padding`).
8. `template-parts/content-flexcontent.php` is the one loop: `have_rows`, `$total_rows`, `$i`, `get_row_layout()` branch per layout, `<section id="<?php section_id($i); ?>" class="<noun>...<?php is_last_row($i,$total_rows); ?>"><div class="container-2xl">`. Hero fields live in a "Hero Content" group rendered by `template-parts/content-hero.php`.
9. ACF local JSON committed in `acf-json/`, group/field keys stable. Site-wide settings in an ACF options page (Club settings). Coaches are a CPT with ACF fields; news are posts. No page content hardcoded in a template.
10. Editor-proof fields: Kind or Style first, conditional logic for the dependent boxes, plain labels, one line of instruction on every field, no pipe or token syntax, nothing that does nothing for the chosen option, Classic Editor, WYSIWYG limited to a small toolbar.

**Markup and CSS**
11. BEM: one root block per layout (kebab noun), `block__element`, `block--modifier`; shared `.container-2xl`, `.content`, `.meta`, `.btn`, `.btn--<style>`; state classes `is-open`, `last-module`.
12. `src/scss/app.scss` with the six-band index (00 Grid ... 05 Theme), partials `base/_variables, _mixins, _fonts, _animations`, `vendor/_reset, _bootstrap`; `:root` under `01. Base` with `--global--*`, `--grid--gutter*`, `--section-padding`, `--container-width` tokens and breakpoint overrides inside `:root`.
13. Components consume tokens only: `@include text(step)`, `var(--section-padding)`, `var(--grid--gutter)`, `var(--global--border-radius-*)`, colour tokens. A literal value means the token is missing, so add the token.
14. `section { position: relative }`, the `last-module` class on the last row, `.meta`, `.section__eyebrow/__heading/__subhead`, `.content` rich-text base. (Chez Koop's base `section { padding-top }` rule is not used: every layout here sets its own padding from `--section-padding`, because v2's sections differ.)
15. Header `header.site-header > .container-2xl > .site-logo + nav.site-nav + .site-cta + .menu-toggle`; footer `footer.site-footer` with `footer__*` BEM; `html.scrolled` and `html.menu-open` state classes; `body_class` whitelist.
16. Images through `section_image()` (lazysizes `data-src`/`data-srcset`/`data-sizes`, `data-aspectratio`, eager and `fetchpriority="high"` for the hero, filtered srcset, SVG inlined), alt text from the media library.
17. Fonts via `<link>` Google Fonts with preconnect in `header.php`; `no-js` to `js` inline script on `<html>`.

**Build**
18. gulp 4 + gulp-sass + autoprefixer + sourcemaps + rename `.min` -> `assets/css/`; `webpack-stream` `src/js/entry.js` -> `dist/js/app.bundle.js` (jquery external, terser); `gulp-imagemin` `src/img` -> `assets/img`; `watch` with BrowserSync proxy; default task = sass, webpack, img, watch.
19. Compiled CSS, source map and JS bundle are committed. `node_modules`, `.env*`, `.DS_Store` ignored.
20. JS: `src/js/entry.js` with `window.theme`, ES imports (gsap + ScrollTrigger, lenis, lazysizes), one jQuery IIFE, `theme.init/animations/menus`, reveals via `.fade-up` + GSAP with CSS pre-state under `html.js`.

**Process**
21. `.cursor/rules/tumbleweeds-theme.mdc` (alwaysApply) and `.cursor/rules/page-templates-location.mdc` and a `SKILL.md` ship with the theme so the next agent or Koop dev follows the same contract.
22. Verify in the browser, not the shell; check the wp-admin edit screens, not only the front end.

## 3. Where this theme deliberately differs (and why)

- **No `section_padding` field or helper.** v2's sections have fixed, differing paddings, all taken from `--section-padding` and the surface tokens in `app.scss`, so a per-section padding switch would only let a volunteer break the design. Add it if a layout ever needs it.

- **Menus:** `wp_nav_menu` on `header-menu` and `footer-menu` as Chez Koop do. Chip asked for the nav in Club settings; Club settings holds the button, the phone-only extra link and a pointer to Appearance, Menus, so a volunteer has one place to start. Putting the links themselves in a Club settings repeater is a one-hour change if preferred.
- **Straight quotes:** `run_wptexturize` is off so text typed in a WYSIWYG box matches text typed in a plain box (and matches v2).
- **News URLs:** permalinks are `/%postname%/` (a posts-only `/news/` prefix forces WordPress verbose page rules and makes unknown URLs fall back to the home page instead of a 404).
- **Pages hide the empty text editor, Featured image, comments and other unused boxes** (`hide_on_screen` on the Hero Content group), so the edit screen is only the fields.

- **Secure Custom Fields is the tested path**, ACF Pro is supported. Chez Koop bundles the Pro zip; this repo is public so it cannot. TGMPA points at wordpress.org instead.
- **Contact Form 7 instead of Gravity Forms** (paid, zip cannot be committed). The contact form and footer sign-up render CF7 forms (shortcode in Club settings, styled with theme tokens, plugin CSS off). Without the plugin they fall back to the mailto form, and the footer also takes a Mailchimp or Flodesk embed code.
- **Hero images use soft-cropped sizes** and CSS `object-position` from a focus slider, instead of the hard-crop `hero` 1920x1080, so the v2 framing survives.
- **Smooth scroll:** Lenis is loaded as Chez Koop does, but it is skipped under `prefers-reduced-motion`.
- **Typekit** is replaced by the three Google Fonts v2 already uses.
