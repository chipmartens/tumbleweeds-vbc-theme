# Tumbleweeds Volleyball Club: WordPress theme

Built the way Chez Koop builds the mode40 theme: ACF flexible content (Secure Custom Fields or ACF Pro), Classic Editor, BEM, SCSS with tokens in the `app.scss` `:root` block, gulp 4, compiled CSS committed.

## Run it locally (no hosting needed)
```
npm install
npm run build        # tokens -> app.scss :root, then app.min.css
npx @wp-playground/cli@latest server --blueprint seed/blueprint.json \
  --mount "$(pwd)":/wordpress/wp-content/themes/tumbleweeds-vbc --port 9400 --login
```
Open http://127.0.0.1:9400. The blueprint installs Secure Custom Fields and Classic Editor, activates the theme, and runs `seed/import.php` (re-runnable; pages, coaches and posts matched by slug). On a real WordPress: install SCF or ACF Pro, activate the theme, then `wp eval-file wp-content/themes/<theme>/seed/import.php`.

## Where things are
- `acf-json/`: generated by `python3 tools/build_acf_json.py`. Edit the field set in that script, not the JSON.
- `src/scss/app.scss`: all styles. Tokens come from `tokens/brand-tokens.json` via `npm run tokens`. No literal colour, font size or gutter in a block.
- `template-parts/content-flexcontent.php`: one block per flexible layout. `inc/lib/flex.php`: helpers.
- `seed/content.json`: all copy. `[Square brackets]` are visible placeholders for unconfirmed facts.
- `tools/sync-brand-assets.py`: re-copy logo SVGs and cutouts from the project folders.
- `tools/shots.js` screenshots every page at 390 and 1440. `tools/export_static.py` writes `preview/` (static, relative links).

Club settings: with Secure Custom Fields 6.9 (tested) a **Club settings** item appears in the admin menu and holds the header button, email, Instagram, info session date and place (pages say `{info_date}` and `{info_details}`, so you change it once; clear both boxes after the event and every line that mentions it disappears), footer status line and complaints contact. If a site has a fields plugin without options pages, the theme falls back to reading the same fields from the front page edit screen (code path present, not tested).

Editing: Pages have "Top of page" and "Page sections". Coaches have their own menu. Club email, Instagram, header button, complaints contact live in "Club settings" (on the front page edit screen when using the free fields plugin).
